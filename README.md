# Интерьер Смета — установщики

Программа для расчёта сметы ремонта и интерьера (Windows 10/11, 64-bit).

**Скачать:** откройте [последний релиз](https://github.com/JasurbekAkhunov/interior-smeta-releases/releases/latest)
и скачайте файл `InteriorSmeta-Setup-<версия>.exe`.

Установленная программа сама проверяет обновления в этом репозитории, скачивает их в фоне
и предлагает перезапуститься.

> Windows может показать предупреждение SmartScreen («Неизвестный издатель»), потому что установщик
> пока не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».
